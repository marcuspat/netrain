Matrix-style packet monitor

Live traffic rendered as terminal rain — you see the network the way the movies promised.

Real threat detection

DDoS and port-scan detection running on the same stream that feeds the visuals.

Built in Rust

Terminal visualizations that stay responsive under load — ratatui, not a browser tab.
